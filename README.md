# PelisFlix - Catálogo Interactivo de Películas

Aplicación web desarrollada con React, Vite y Tailwind CSS para la exploración interactiva de películas. Permite realizar búsquedas en tiempo real, filtrar por género, año, calificación y películas favoritas, ver detalles en pantalla emergente y calificar contenido.

1. Clonar el repositorio o descargar los archivos.
